# Project Notes

## Project Type

Embedded Systems Software Simulation

## Development Platform

Arduino UNO

## Simulation Platform

Wokwi

## Programming Language

Embedded C / Arduino C++

## Hardware Status

No physical hardware is used.

The complete prototype is implemented and tested virtually.

## Sensor Status

A software-generated pulse waveform is used instead of a physical pulse sensor.

## Purpose

The purpose is to demonstrate:

- sensor signal modeling
- signal sampling
- heartbeat detection
- BPM calculation
- basic filtering
- threshold-based decision making
- display interfacing
- LED control
- buzzer control
- embedded programming

## Medical Disclaimer

This is an educational embedded systems prototype.

It is not a medical diagnostic device.

Hobby-grade sensors and simulated signals can be approximate and must not be used for medical decisions.
